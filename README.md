# claude-watchdog

> ⚠️ **Deprecated** — replaced by [claude-tmux-dog (cdog)](https://github.com/SnowAIGirl/claude-tmux-dog)

**cdog** is a Claude Code process manager with far more capabilities:
- Autonomous 24/7 operation (auto-nudge, auto-recovery)
- Dual-layer context defense (proactive pane watcher + reactive log watcher)
- Inter-agent message bus
- Desktop notifications with interactive actions
- API error classification with per-kind thresholds
- Circuit breaker for failure loops

```bash
npm install claude-tmux-dog -g
cdog start ./cdog.json
```

See [github.com/SnowAIGirl/claude-tmux-dog](https://github.com/SnowAIGirl/claude-tmux-dog) for full documentation.
